## 🏗️ Architecture Overview

### Clean Architecture Layers

```
presentation/     → UI, State Management, Providers
    ├── pages/           → LoginPage
    ├── widgets/         → CustomTextField, PasswordField, PrimaryButton
    └── providers/       → AuthState, AuthNotifier, AuthProviders

domain/          → Business Logic
    ├── entities/        → LoginEntity, UserEntity
    ├── repositories/    → AuthRepository (interface)
    └── usecases/        → LoginUseCase, GetCurrentUserUseCase, LogoutUseCase, CheckAuthStatusUseCase

data/            → Data Sources & Implementation
    ├── models/          → LoginRequestModel, LoginResponseModel, UserModel (with freezed)
    ├── datasources/     → AuthRemoteDataSource, AuthLocalDataSource
    └── repositories/    → AuthRepositoryImpl

core/            → App-wide Infrastructure
    ├── constants/       → ApiConstants, AppConstants
    ├── theme/           → AppColors, AppTheme
    └── network/         → DioClient with interceptors

config/          → Configuration
    └── router/          → AppRouter with go_router
```

## 🔗 Backend Integration

### API Endpoints
✅ POST `/api/v1/auth/login/` - User login
✅ GET `/api/v1/auth/me/` - Get current user
✅ POST `/api/v1/auth/logout/` - User logout
✅ POST `/api/v1/auth/refresh/` - Refresh access token

### Request/Response Format
```dart
// Login Request
{
  "username": "string",  // Accepts: username, email, phone, or "First Last"
  "password": "string"
}

// Login Response
{
  "access": "jwt_token",
  "refresh": "jwt_token",
  "must_change_password": false,
  "school_code": "string",
  "tenant_id": "string",
  "portal_type": "admin|teacher|parent|student"
}
```

### Security Features
✅ JWT token-based authentication
✅ Automatic token refresh on 401 (Auth Interceptor)
✅ Encrypted token storage (flutter_secure_storage)
✅ Platform-specific secure storage:
   - Android: EncryptedSharedPreferences
   - iOS: Keychain with first_unlock
✅ Public endpoint detection (no auth for login/school-info)

## 📖 Code Examples

### 1. Login Usage
```dart
// In LoginPage
ref.read(authNotifierProvider.notifier).login(username, password);

// Listen to state changes
ref.listen<AuthState>(authNotifierProvider, (previous, next) {
  next.maybeWhen(
    authenticated: (user) => print('Welcome ${user.firstName}'),
    error: (message) => showError(message),
    orElse: () {},
  );
});
```

### 2. Protected Route Check
```dart
final authState = ref.watch(authNotifierProvider);
final isLoggedIn = authState is _Authenticated;
```

### 3. Get Current User
```dart
final authState = ref.watch(authNotifierProvider);
authState.maybeWhen(
  authenticated: (user) => Text('Hello ${user.fullName}'),
  orElse: () => Text('Guest'),
);
```
